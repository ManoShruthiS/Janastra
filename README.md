# JANASTRA

Multilingual live caption online meeting platform powered by Gnani AI Prisma v3.0.

## Overview
JANASTRA provides real-time Indian regional language speech-to-text, translation, and video conferencing.

## Architecture
- **Backend**: FastAPI, WebSockets, WebRTC signaling, Gnani AI Prisma v3.0 SDK
- **Frontend**: Vite, React, TypeScript, Tailwind CSS

## Setup & Run
```bash
# Backend
cd backend && python run.py

# Frontend
cd frontend && npm run dev
```
